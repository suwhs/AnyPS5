# libkernel

## add Functional

- [signals](../../../core/libs/prx/libkernel/System/src/Signals.cpp) (libkernel) - an `SA_SIGINFO` handler receives a synthetic `siginfo` (guest signal number, the call site's `si_code`, the process id, union zero; a queued signal keeps the `sigqueue` record) and a `ucontext` built on the delivery stack. Its `rip`, `rsp` and `rbp` are the guest's return from the libkernel signal entry that delivered it, so a frame-pointer guest can walk its stack; `sigmask` is the guest mask with the handlers' holds; `cs`, `ss`, `rflags`, `mc_len`, `mc_fpformat`, `mc_ownedfp` and an `fxsave64` image are captured so `sigreturn` and `setcontext` accept the context. The other registers, the trap fields and `uc_link`/`uc_stack`/`uc_flags` are zero, the selectors, flags and FP/SIMD area are the delivering thread's rather than the interrupted instruction's, the context lives only for the handler call, and a delivery from another system library names that library's frame. Closes when: measured on a PS5.
